# CondoUrban — web-app (Angular PWA)

Portal único com layouts/guards por perfil (T6). UI: Angular Material + tokens em `packages/ui-brand`.

## Setup

Atalho na raiz: `scripts\start-app.bat`.

```bash
cd apps/web-app
npm install
npm start
```

Abre http://localhost:4200 — API em http://127.0.0.1:8000.

Demo: `morador@example.com` / `Demo@1234`
