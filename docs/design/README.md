## Decidir a cara do produto

1. Abra o hub [`../../index.html`](../../index.html), a [landing](../../landing/index.html) ou [`sugestoes/index.html`](sugestoes/index.html) (`scripts\start-local.bat`).
2. Compare e preencha a tabela **Decisão** em [`sugestoes/README.md`](sugestoes/README.md).
3. Registre em **D1 / D2 / D3 / T4** ([05-perguntas-abertas.md](../plano/05-perguntas-abertas.md)).
4. Atualize `paleta-cores.md` / `tipografia.md` com a escolha final.

Quando existir código: espelhar em `packages/ui-brand`.
