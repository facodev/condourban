# Tipografia

Complemento da [paleta de cores](paleta-cores.md). Status: provisão (pergunta **D3**).

| Uso | Família sugerida | Fallback |
|-----|------------------|----------|
| UI app | Source Sans 3 ou IBM Plex Sans | system-ui, sans-serif |
| Display landing | Fraunces ou Literata | Georgia, serif |
| Monospace (códigos) | IBM Plex Mono | ui-monospace, monospace |

## Escala (app)

| Token | Tamanho | Peso | Uso |
|-------|---------|------|-----|
| `--text-xs` | 12px | 400 | Legendas |
| `--text-sm` | 14px | 400 | Secundário |
| `--text-md` | 16px | 400 | Corpo |
| `--text-lg` | 18px | 600 | Subtítulos |
| `--text-xl` | 22px | 600 | Títulos de seção |
| `--text-hero` | 36-48px | 700 | Landing apenas |

Evitar Inter, Roboto e Arial como identidade de marca.
